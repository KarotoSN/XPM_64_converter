# XPM 64 Converter

A tool that automatically resizes images to 64x64 resolution and converts them into the XPM format required for 42 graphic projects.

## Description

XPM 64 Converter is designed to simplify the image preparation workflow for 42 School graphic programming projects such as **so_long** and **cub3d**. It takes any image file and automatically:

- Resizes the image to 64x64 pixels
- Converts it to XPM format (.xpm)
- Generates the necessary code for immediate use in your projects

## Features

✨ **Automatic Resizing** - Scales any image to the standard 64x64 resolution  
🎨 **XPM Conversion** - Converts images to XPM format with proper formatting  
⚡ **One-Click Processing** - Simple interface for quick conversions  
📦 **Ready to Use** - Generated files are compatible with 42 graphic projects

## Usage

1. Upload or select an image file
2. The tool will automatically resize and convert it
3. Download your XPM file

## Supported Input Formats

- Common image formats (JPG, PNG, BMP, GIF, etc.)

## Requirements

- Modern web browser with JavaScript support
